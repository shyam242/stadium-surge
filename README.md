# Stadium Surge
Next.js 14 + TypeScript + Tailwind + Recharts + Leaflet (Esri satellite imagery of HPCA Stadium, Dharamsala).
    npm install && npm run dev   # http://localhost:3000
Simulation: lib/engine.ts · Dataset (from Sync_V1.xlsx): lib/data.ts

The scenario simulator uses 100,000 attendees, 40% Airtel share and 18% concurrent usage by default. The deployment page's proposed plan loads 4 COWs, 10 small cells, radio upgrades and about 1 km of fibre within the ₹400 lakh allocation. Historical match measurements are shown separately from modelled scenario results.
